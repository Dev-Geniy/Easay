# Easay 6.3.1 — бесплатная платформа английского языка

**Репозиторий:** Dev-Geniy/Easay · **11 направлений, 396 уроков по 36 в каждом** · PWA · Cloudflare Worker + D1.

## Возможности приложения

- Полностью бесплатные офлайн-доступные уроки и 1 584 выражения (4 на урок).
- Пять этапов каждого урока: знакомство с фразой, выражения, диалог, карточки закрепления, тест из 3 вопросов.
- Проходной результат обычного теста — 2/3. После проверки появляется окно разбора: реальные выбранные/верные ответы, дополнительное объяснение Groq (если пользователь включил автоматическую помощь), необязательные вопросы ИИ и пересдача.
- «Повторение» по умолчанию показывает только слова со сроком повторения на сегодня или раньше. Дополнительные тренировки с любыми сохранёнными словами запускаются отдельно.
- Домашняя страница, каталог 11 курсов, еженедельный план, занятия в паре, сценарии разговорной практики, ИИ-наставник, достижения и локальная статистика.
- Прогресс и текущая учебная история хранятся в localStorage; экспорт и импорт JSON позволяют сделать резервную копию.
- Озвучивание английского через браузерный Web Speech API. Не предполагается объективная проверка произношения.

## Финальный экзамен и сертификат

- Финальный экзамен — **40 вопросов по всем 36 урокам курса**, 2,5 балла за верный ответ, проходной балл **90/100**.
- Серверный режим при настроенной Cloudflare D1 создаёт **одну попытку на браузер за скользящие 24 часа**. Попытка действует **45 минут**. Ученики, использующие один Wi-Fi в разных браузерах, имеют независимые лимиты.
- После перезагрузки страницы Easay пытается **восстановить ту же неистёкшую серверную попытку**: идентификатор, ответы и позицию. Пакет вопросов заново запрашивается и проверяется на сервере. Повторное открытие активной попытки не списывает ещё одну.
- Без сервера или после исчерпания лимита остаётся **тренировочный экзамен**; он не выдаёт проверяемый сертификат.
- Сертификат создаётся после **серверной проверки** и содержит добровольно введённое **ФИО** и рассчитанный сервером **процент верных ответов**. Пользователь **не может изменять процент** вручную. Согласие на публичную публикацию ФИО — отдельное и необязательное.
- **Достоверность:** сертификат подтверждает успешную сдачу *внутреннего экзамена Easay*. Он **не проверяет юридическую личность**, не подтверждает сервером прохождение всех уроков и не является государственной или независимо аккредитованной квалификацией.
- Анонимный идентификатор браузера можно сбросить/сменить, поэтому ограничение не является строгой защитой от умышленных повторных попыток.

## Разработка, сборка, тесты

```bash
npm test
npm run build
```

GitHub Actions запускает проверки синтаксиса, тесты и статическую сборку на каждый push и pull request. `scripts/build.mjs` копирует `public/` в `dist/`.

Для просмотра статического сайта локально: `python3 -m http.server 8080 --directory public`. API в таком режиме не работает. Для серверных сценариев нужен Cloudflare Worker и действующие биндинги.

## Публикация

Текущая конфигурация: `wrangler.toml`, `worker/index.js`, `functions/api/exam.js`, `functions/api/certificate.js`, `netlify/functions/ai.mjs` (серверный AI-модуль, используемый Cloudflare Worker). D1-биндинг `EASAY_DB` указан в `wrangler.toml`; существующие секреты `GROQ_API_KEY` и `CERT_HASH_SECRET` сохраняются через `keep_vars=true`. **В GitHub не хранить секретные ключи.**

См. [Cloudflare Worker](docs/cloudflare-worker.md) и [сертификаты](docs/certificates.md).

## Ограничения и честные оговорки

- Бесплатный Groq может временно не отвечать. Локальный лимит 8 успешных AI-запросов в сутки — UX-ограничение, а не серверная гарантия. Для крупной публичной аудитории нужны более строгие меры защиты API и контроля затрат.
- Офлайн-прогресс может быть утрачен при очистке данных браузера; штатной облачной синхронизации пока нет.
- Учебные фразы и переводы требуют дополнительной редакторской педагогической проверки; диалоги некоторых уроков составлены из четырёх учебных выражений.
- Тесты CI не заменяют ручную проверку поведения на телефонах, поддержки Web Speech и фактической конфигурации Cloudflare.
- Все уроки бесплатные, донаты добровольные. Отображаемое назначение пожертвований в приложении не является автоматическим подтверждением перевода средств.

## Easay 6.3 — новая главная и Карточки 2.0

- Главная сохраняет **одно главное действие**: продолжить незавершённый урок основного курса. Контекст и прогресс берутся из реальных данных ученика (36 уроков на курс, число к повторению рассчитывается из дат).
- Две простые вторичные кнопки: **Повторение** и **Мой прогресс**. Последняя раскрывает текущий маршрут, статистику и достижения. Никакой несуществующей «оценки навыков» не показывается. Каталог и план остаются доступными отдельными спокойными ссылками.
- Расписание карточек 2.0 позволяет оценить **Не помню / С трудом / Легко** после переворота. Интервалы: 10 минут; 1–14 дней по достигнутому уровню; 3–90 дней для уверенно вспомнившихся фраз. Интервалы рассчитываются локально, без Groq.
- Точность повышена до времени `dueAt` в миллисекундах с локальной датой `due` для совместимости. Старые записи `{level,due}` из `easay:v3:learner` продолжают работать и постепенно получают новые поля. Данные ученика и экзаменационные попытки не меняются.
- Дополнительная свободная тренировка отделена от планового повторения: показывает все сохранённые фразы, но **не влияет на интервалы**. Возврат к повторению по расписанию доступен в любой момент.
- Изменения для мобильных: отзывчивые карточки действий и крупные доступные кнопки оценки, текстовые подсказки без принудительных анимаций. Новые файлы добавлены в офлайн-кеш PWA.

## Easay 6.3.1 — обновление расписания и завершённых курсов

- Если до следующей карточки осталось 10 минут или больше, раздел «Повторение» показывает ближайшее время, а главная — следующую запланированную дату вместо вводящего в заблуждение «Сегодня всё повторено».
- Когда срок следующего повторения наступает в открытом приложении, главная / пустой экран повторения обновляются сами; после возвращения во вкладку даты пересчитываются. Во время активного тестирования карточки не прерываются.
- Для курса, где завершены все 36 уроков, главное действие теперь ведёт к итоговому экзамену по курсу; до завершения — к следующему уроку.
- Даты и интервалы продолжают храниться локально и совместимы со старым форматом `{level,due}`; API, D1 и сертификаты не изменены.
